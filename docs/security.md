# Security — Enterprise ACV & Revenue Intelligence

- Use least-privilege Snowflake roles and read-only reporting access where possible.
- Keep credentials, connection strings, and service-account details outside source control.
- Separate development, test, and production workspaces.
- Do not expose real customer, contract, or financial data in public artifacts.
- Restrict row-level access when customer or geography visibility differs by audience.
- Validate published datasets before external sharing.
- Retain metric definitions and transformation lineage for auditability.

This public repo contains synthetic examples only.
